# mongodbDemo (Spring Boot 4 + MongoDB, Java 21)

A minimal Spring Boot service that connects to MongoDB and exposes one test endpoint.

## Tech Stack
- Java 21 (Temurin)
- Spring Boot 4.0.3
    - spring-boot-starter-web
    - spring-boot-starter-data-mongodb
- Lombok
- MongoDB
- Docker (optional)

---

## Endpoints

- `GET /test` → returns `"MongoDb connected! Order count = X"`
